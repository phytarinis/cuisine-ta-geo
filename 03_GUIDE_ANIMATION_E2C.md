# Guide d'animation formateur — E2C Coutras

## Avant la séance (5 minutes de préparation)
- Un Chromebook/PC, vidéoprojecteur, affichage du navigateur en plein écran, souris fonctionnelle, deux ardoises ou papiers + feutres.
- Tester **index.html** hors ligne. Afficher la vue à 100%, contrôler que les repères de la carte sont visibles.
- Former 2 brigades avec 3 à 5 stagiaires chacune ; choisir noms et désigner un porte-parole par défi, qui peut changer pendant la partie.
- Expliquer qu'il s'agit d'un défi de **géographie**, pas d'un concours de gastronomie : les plats servent d'indices. Plusieurs cultures ou territoires peuvent partager une spécialité ; le jeu précise des associations usuelles.

## Lancement (5 min)
Dire : « Vous allez vous affronter à travers cinq épreuves. Certaines se jouent simultanément, d'autres chacun votre tour. La cuisine vous donnera des indices pour retrouver des villes, départements, régions, pays et continents. Vous pouvez discuter entre équipiers avant de répondre. »

Règles à dire : pas de téléphone nécessaire ; respect et discussion ; une seule réponse finale ; joker x2 une fois dans les manches 2 ou 3, annoncé avant le défi ; les équipes ont le droit de se tromper.

## Pendant le jeu (35 min environ)
1. L'apéro local : deux ardoises, deux réponses simultanées, saisir A/B dans l'application après révélation, lire et expliciter une correction.
2. À quelle sauce ? : équipe nommée, discussion, choix de révéler ou non indice supplémentaire ; après une erreur, laisser 15–20 secondes à l'autre équipe pour proposer un vol.
3. GPS en PLS : demander aux stagiaires **pourquoi** ils choisissent tel repère (nord/sud/est/ouest, proximité d'autres villes) ; ne pas faire semblant de placer un repère à l'aveugle ; utiliser l'affichage correction pour distinguer ville, département et région.
4. Passeport gourmand : deux ardoises, d'abord pays puis continent ; montrer ensuite le pays sur la carte.
5. Coup de feu : faire tourner le rôle de porte-parole ; 90 secondes chacun ; formateur peut mettre le chrono en pause si incident technique.

## Débrief / transfert (10–15 minutes, après le jeu)
Demander :
- « Une **commune** et une **ville**, c'est pareil dans tous les cas ? Qu'est-ce qu'un département ? Une région ? » (clarifier : commune = unité administrative ; « ville » est un terme courant et statistique qui n'est pas toujours synonyme strict de commune.)
- « Pouvez-vous expliquer le chemin Coutras → Gironde → Nouvelle-Aquitaine → France → Europe ? »
- « Comment avez-vous reconnu les lieux sur les cartes, quels repères vous ont aidés ? »
- « Dans quelle situation réelle auriez-vous besoin de ces repères ? Départ en stage, déplacement, entretien, formation, visite ? »
- « Comment avez-vous décidé ensemble quand vous n'étiez pas d'accord ? »

### Observation préparatoire UP2C (pas validation)
- **2d Se repérer dans l'espace et le temps** : identifie le bon type de territoire ; utilise un repère nord/sud/est/ouest ; situe une ville sur carte ; corrige une localisation erronée après comparaison.
- **4c Apporter sa contribution au collectif** : propose une réponse ; participe à une discussion ; prend une responsabilité dans sa brigade ; contribue à la décision finale.
- **1c Échanger oralement avec autrui** : demande une clarification ; répond à un équipier ; reformule ; explique un choix de manière compréhensible.

La partie ne valide aucun palier UP2C automatiquement. Réinvestir les observations dans le suivi global du parcours et, si prévu, dans une autoévaluation avec un exemple concret.

## Pour aller plus loin en Classroom
Mission courte possible : « Choisis une spécialité connue dans ta famille ou découverte aujourd'hui ; indique le plat, la ville ou le territoire auquel il est associé, son département/région ou pays/continent, et place ce lieu sur une carte. Écris ce que tu as vérifié et une manière d'utiliser la géographie dans une situation réelle. » Les réponses sont des recherches personnelles, pas des scores du jeu.
